# 本地浏览器打开（Cursor Remote SSH）

远程服务只监听 `127.0.0.1:8770`，不暴露公网，也不托管整个仓库。

## 方式 A：Cursor 端口转发（推荐）

1. 远程已启动：`python3 serve_workbench.py --port 8770`
2. 在 Cursor 端口面板把 `8770` 转到本机（Private）。
3. 本机浏览器打开：`http://127.0.0.1:8770/`

## 方式 B：SSH 本地转发

```bash
ssh -L 8770:127.0.0.1:8770 <user>@<remote-host>
```

然后在本机打开：`http://127.0.0.1:8770/`

## 验收

- 页面标题含「科学认证工作台」
- 任选一题点击播放器，视频应能实际播放（不仅是页面 200）
- 媒体路径形如 `/media/*.mp4`，不要用 `file://`
